# Xfit
O X-Fit é um aplicativo de receitas e comidas saudáveis, com uma descrição completa de todos os seus componentes e nutrientes.


Dentro de suas funcionalidades é possível realizar o login e cadastro completo do usuário desde os dados mais simples para até endereços para entrega,é possivel após o cadastro e o login fazer alistagemm destes dados antes cadastrados, é possível cadastrar novas receitas e lista-las após isso e até mesmo classificar essas receitas e comidas.  


Tecnologia utilizadas: Foi utilizado em tal projeto o FlutterFlow, a linguagem Java, o Dbeaver e o Render.
